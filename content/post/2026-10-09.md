### Critical Telegram Desktop bug: hackers can steal accounts with a single click

Telegram Desktop versions before 7.2.9 contain a critical vulnerability (CVE-2026-10718, CVSS 8.6) that allows attackers to inject hidden commands via crafted tg:// links using unescaped semicolons. A victim who clicks one malicious link in a Telegram group can have session files stolen, enabling account takeover on another device. Users should update Telegram Desktop, restrict group invites, set a local passcode, and stop automatic downloads.

### Linux Patches Finally Make Hibernation Possible In Secure Boot / Lockdown Mode

New patches proposed by Matthew Garrett at NVIDIA would allow system hibernation when the Linux kernel runs in lockdown mode, including under UEFI Secure Boot.
