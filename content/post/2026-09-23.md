## 🔐 Security & Privacy

### Leaked GitHub key left lead US public health agency’s code exposed to poisoning

A leaked GitHub private key tied to CDC-linked repositories may have exposed private code and Azure cloud systems, with write access that could have allowed attackers to poison code. GitGuardian said the key was exposed in April 2025 and remained usable until it was revoked on September 18 after being reported to HHS. In a wider review, researchers found 474 leaked GitHub App keys still worked, including some with write or admin access, though no attacker use tied to the CDC key has been confirmed.

- [Leaked GitHub key left lead US public health agency’s code exposed to poisoning](https://cybernews.com/security/leaked-github-key-cdc-health-agency-code-exposed-poisoning/) — *cybernews.com*

### Adaptive Lossless Floating-Point Encoding in Apache Parquet

### Transit rewards (Waymo pays you to take the train)

Waymo announced a transit rewards program, initially in the San Francisco Bay Area, that gives riders $2.85 in Waymo Cash when they take a Waymo ride and public transit within two hours of each other using a linked Visa card. The program will start with employees before rolling out publicly in coming weeks, and it applies to 27 Bay Area transit agencies that accept contactless Visa tap-to-pay. Waymo is also partnering with Caltrain to lease 40 station parking spaces for staged vehicles.
