### Octomind – open-source AI harness that saves your tokens, static rust

Octomind is a CLI-first open-source AI coding agent runtime that gives LLMs repo access via MCP tools for file operations, shell commands, code search, and sub-agents, supporting interactive, piped, daemon, WebSocket, and ACP workflows. It is built for autonomous use with TOML-based policy guardrails, flexible model/provider selection, session compression, and packaged specialist agents from taps. Its README claims it solved 24 of 25 held-out tasks at lower cost than the closest competitor and includes installation and quick-start instructions.

- [Octomind – open-source AI harness that saves your tokens, static rust](https://github.com/Muvon/octomind) — *github.com*

### AI agents hallucinate prices: LLM grounding with live data

The article explains that AI agents often report wrong product prices from stale memory, bad web pages, or tools that falsely report success. It tests models that matched live prices for only 2 of 15 products from memory, and even with web search still produced wrong prices despite source links. It recommends grounded agents that use live scraped data, detect failed checks clearly, and let code—not the model—insert each price into the answer.

### The Nordic Token Tax

A study of 3,000 identical sentences across 12 recent AI models from nine labs found that every model charged more for Swedish, Norwegian, Danish, and Finnish than for English because non-English text is split into more tokens. Swedish cost 32% to 68% more, while Finnish cost up to twice as much. The extra tokens also mean higher billing and slower responses for the same content.

- [The Nordic Token Tax](https://research.klang.ai/papers/the-nordic-token-tax) — *research.klang.ai*
