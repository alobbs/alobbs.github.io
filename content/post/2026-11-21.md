### ClawDOS – An AI coding agent for DOS

ClawDOS is an AI coding agent that runs on an IBM PC XT—an 8088 at 4.77 MHz with 640K RAM and a CGA card—and is launched by typing `CLAWDOS` at the DOS prompt. Its 176 KB `HARNESS.EXE` speaks the Claude Messages API directly, relying on a bridge PC only for TLS, and can read and edit files, write and compile programs with Turbo C, run them, inspect screen output, and keep notes between conversations. The repository was written entirely by Claude, with the author describing it as an experiment in pushing an AI coding agent under vintage hardware constraints.

- [ClawDOS – An AI coding agent for DOS](http://ricapar.net/ClawDOS/) — *ricapar.net*

### RCE in Gnupg

GPGME versions prior to 2.3.1 contain a critical double-free vulnerability (CVE-2026-129975) triggered by an OpenPGP key with a crafted very long user ID, potentially enabling data exfiltration and possibly remote code execution. GPGME 2.3.1 fixes the flaw, and affected software using earlier versions should update immediately.

- [RCE in Gnupg](https://lists.gnupg.org/pipermail/gnupg-announce/2026q4/000517.html) — *lists.gnupg.org*

### OpenRouter prompts to Minimax may have been read

OpenRouter emailed users that a security researcher’s test URLs in prompts sent to MiniMax models from July to October 2026 were accessed by a third party 40 to 130 hours later, including when other providers forwarded requests to MiniMax. OpenRouter said the issue appears to lie with MiniMax and the providers that forwarded to it, not OpenRouter, and that prompts and outputs may have been read. It has removed the Zero Data Retention label from the affected MiniMax-model endpoints while investigating.

### Twin films are films with the same or similar plots released with a short time

Twin films are films with the same or similar plots produced and released close together by different studios, often because multiple companies invest in similar scripts at the same time or due to shared screenplays, staff movement, or industrial espionage. Studios sometimes avoid such collisions by delaying, merging, or abandoning projects. Notable examples include competing adaptations and biopics released around the same period.

### How to generate an accessible color palette from a single color

Pablo Di Filippo describes a method for generating accessible color scales from a single color by assigning each step a target contrast ratio against the background and then computing the OKLCH lightness that meets it, as used in the newly MIT-licensed TaishoDS Core. He says an earlier approach based on evenly spaced lightness failed, and testing 4,096 starting colors in light and dark mode produced 81,920 steps whose text contrast never fell below 4.63, above WCAG AA’s 4.5. The article also notes exceptions such as yellow hues and cases the method does not cover.

- [How to generate an accessible color palette from a single color](https://taisho.design/en/blog/accessible-color-palette-from-one-color) — *taisho.design*
