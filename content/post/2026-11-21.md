### RCE in Gnupg

GPGME versions prior to 2.3.1 contain a critical double-free vulnerability (CVE-2026-129975) triggered by an OpenPGP key with a crafted very long user ID, potentially enabling data exfiltration and possibly remote code execution. GPGME 2.3.1 fixes the flaw, and affected software using earlier versions should update immediately.

### How to generate an accessible color palette from a single color

Pablo Di Filippo describes a method for generating accessible color scales from a single color by assigning each step a target contrast ratio against the background and then computing the OKLCH lightness that meets it, as used in the newly MIT-licensed TaishoDS Core. He says an earlier approach based on evenly spaced lightness failed, and testing 4,096 starting colors in light and dark mode produced 81,920 steps whose text contrast never fell below 4.63, above WCAG AA’s 4.5. The article also notes exceptions such as yellow hues and cases the method does not cover.

- [How to generate an accessible color palette from a single color](https://taisho.design/en/blog/accessible-color-palette-from-one-color) — *taisho.design*

### Twin films are films with the same or similar plots released with a short time

Twin films are films with the same or similar plots produced and released close together by different studios, often because multiple companies invest in similar scripts at the same time or due to shared screenplays, staff movement, or industrial espionage.
