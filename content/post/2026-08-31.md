### Privilege escalation from IIS AppPool to NT Authority/SYSTEM

An attacker with RCE on an IIS web server can escalate from IIS AppPool identity to NT Authority/SYSTEM by exploiting Windows' automatic elevation of the AppPool identity to the machine account when accessing network resources. ### C++26 Library Hardening Experiments

C++26 adds a "hardened" standard library mode that turns precondition violations, such as out-of-bounds `std::vector::operator[]`, from undefined behavior into terminating contract violations.
