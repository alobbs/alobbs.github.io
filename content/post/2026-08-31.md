### Privilege escalation from IIS AppPool to NT Authority/SYSTEM

An attacker with RCE on an IIS web server can escalate from IIS AppPool identity to NT Authority/SYSTEM by exploiting Windows' automatic elevation of the AppPool identity to the machine account when accessing network resources. This is done by submitting a certificate signing request to an Active Directory Certificate Services (AD CS) endpoint, obtaining a machine account certificate, and using it with S4U2Self to impersonate an administrator.

### CobaltC – The Successor to C?

CobaltC is a statically typed systems programming language designed as a successor to C, emphasizing explicit ownership, deterministic destruction, compiler-checked borrowing, inferred lifetimes, nullability, bounds safety, structured errors, and safe concurrency, while also allowing explicit unsafe and foreign-function interface operations.
