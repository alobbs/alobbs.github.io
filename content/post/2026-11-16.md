### The World's Strongest Sokoban Solver

Soksolv outperforms all published Sokoban solvers on the standard Large and Open benchmark suites, solving more levels—including 24 world-first automated solves—and running about 3.3x faster in total time on levels other solvers solve. It was built without handwritten code using a long Claude Code session and roughly 430 subagents, at an API-equivalent cost of about $3,500, with 15,000 vCPU-hours for research, verification, and benchmarks. The project used an iterative hill-climbing approach with a frozen verifier and separate promotion suites, and was developed from scratch rather than on top of an existing solver.

### Hackers can crash millions of Nginx, Apache, SSH servers using NoisyTCP Linux kernel flaw

A newly disclosed 11-year-old Linux kernel flaw, dubbed NoisyTCP, allows unauthenticated remote attackers to crash servers running Nginx, Apache, SSH, and other plain TCP services with default configurations. The bug currently enables denial-of-service attacks, though researchers are investigating whether deeper exploitation is possible. Fixes are in the upstream Linux kernel and some distributions, but major distributions may not receive patches immediately.

### Designing a reliable unplanned failover

Neki’s Admin cannot determine from its own health check whether a Postgres primary has failed or is only unreachable, so unplanned failover requires corroborating evidence. Neki queries replicas and classifies the primary as dead only when Admin cannot reach it and at least one reachable replica reports broken replication with no contradicting replica evidence. If neither the primary nor any replica is reachable, Admin waits rather than risk promoting a second writable primary.

- [Designing a reliable unplanned failover](https://planetscale.com/blog/designing-a-reliable-unplanned-failover) — *planetscale.com*
