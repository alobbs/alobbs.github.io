### Sending packets directly from BPF

Tetragon’s BPF-based monitoring depends on a user-space agent to forward data, creating a vulnerability if the agent is killed. Developers proposed using netpoll to let BPF programs send UDP packets directly to remote servers, bypassing user-space, but concerns remain about UDP’s lack of network stack controls and potential bandwidth contention.

### stinkpot: sqlite-backed shell history

Stinkpot is a compact SQLite-backed shell-history searcher for bash, written in about 400 lines of Go and modeled after atuin but with a narrower feature set focused on session-agnostic history management and a reverse-search TUI. It can be set up via a NixOS home-manager module or by evaluating its init script in .bashrc, and users import existing bash history with the `stinkpot import` command.

- [stinkpot: sqlite-backed shell history](https://tangled.org/oppi.li/stinkpot) — *tangled.org*

### the perils of parsing type inference declarations in c

A parsing ambiguity in C23 causes GCC and Clang to disagree on declarations like `auto x = 67` when `x` is a typedef: GCC treats it as a storage-class specifier and errors, while Clang correctly shadows the typedef. The standard lacks explicit disambiguation, and adding attributes further complicates parsing, with neither compiler backtracking when initial assumptions are wrong.

- [the perils of parsing type inference declarations in c](https://sebsite.pw/w/20260725-auto.html) — *sebsite.pw*

### UK AISI / Caisi Preliminary Assessment of Kimi K3's Cyber Capabilities

The UK AISI and US CAISI evaluated Moonshot AI's Kimi K3 model, finding it outperformed other open-weight models on the ExploitBench benchmark (32% vs 24%) but failed to achieve arbitrary code execution on any of 41 tasks, unlike top models which succeeded on 20/41 tasks overall. Kimi K3's cyber capability estimate has a larger confidence interval because it was derived from a single benchmark.
