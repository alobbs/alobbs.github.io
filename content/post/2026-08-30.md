### Arbitrary code execution in QubesOS via copy-to-VM error reporting backchannel

Qubes Security Bulletin 118 details a vulnerability in `qvm-copy-to-vm` error reporting that lets a malicious qube inject arbitrary commands into dom0 when a user copies a file to it. Users only need to update normally to receive the security patches.

### Rust Function Overloading - Call for Experimentation

The Rust Project and Rust Foundation are experimenting with function overloading through the nightly `#[rustc_splat]` feature, aiming to make FFI calls, particularly to C++, more ergonomic by allowing overloaded functions to be called with separate arguments instead of tuples. The unstable feature is available for compiler and interop tool developers to test, but it may change or be removed. The experiment explores how overload resolution can work within Rust’s trait system while preserving maintainability and expected behavior.
