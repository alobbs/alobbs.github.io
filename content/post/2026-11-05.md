### MCP Explained

The Model Context Protocol (MCP) is an open standard for connecting AI applications to the tools and data they use. A server advertises its capabilities, the host app presents them to the model, and when the model requests an action, the app calls the server and returns the result; the model never communicates with servers directly. MCP uses JSON-RPC over stdin/stdout or an HTTP endpoint and defines methods, capability negotiation, transports, and authentication rather than being REST.

### SSH Security Vulnerability

The articles trace Unix’s convention of using `*` in the password field to disable logins, beginning with Bill Joy’s 1980 entry for the `daemon` account.
