### Amutable Foundations Technical Overview

Lennart Poettering, Michael Vogt, and Joaquim Rocha published a technical overview of Amutable Foundations, comprising Amutable OS (AOS) and the Amutable Control Plane (ACP). AOS is an image-based Linux OS built from Fedora packages into immutable, bit-identical disk images assembled at build time rather than installed on deployed systems, eliminating drift and improving reproducibility, integrity, and testability; it enforces strict security defaults such as no shell, SSH, or language interpreters by default and activates only signed images, while systems merge typically fewer than five coarse images and split large or specific components into system extensions. ACP tracks, controls, updates, and verifies fleets of AOS installations.

- [Amutable Foundations: A Technical Overview](https://amutable.com/blog/amutable-foundations-technical-overview) — *amutable.com*

## 🔒 Security & Privacy

### Forwarded Without Question: How Web Frameworks Overtrust the Forwarded Header

Web frameworks including Rails, Spring, and Jetty read the Forwarded header by default, while most reverse proxies and CDNs do not modify it, allowing untrusted client-supplied values to pass through and be trusted by applications. This can enable client IP and hostname spoofing, so proxies and applications should agree on trusted headers and proxies should drop untrusted forwarding headers.

- [Forwarded Without Question: How Web Frameworks Overtrust the Forwarded Header](https://www.lkoskela.fi/blog/2026-11-05-forwarded-without-question/) — *lkoskela.fi*

## 🐧 Linux & Open Source

### Asahi Linux 7.3 Progress Report

Asahi Linux is moving its repositories to GPLv2-or-later, citing bad-faith attempts to exploit its MIT licensing, while its Linux 7.3 report details continued upstreaming of the macaudio and AVD drivers, initial Devicetrees for M4 Pro/Max and M5, and a shift toward upstream-first development. M3 support is now generally available without the EXPERT flag, DCP enablement improves performance, battery life, sleep, and notch-area use, Thunderbolt support is under kernel review, and SPTM-enabled macOS virtualization in m1n1 aids reverse engineering, though M5 introduces Exclaves-related challenges. Gaming is becoming more viable on M1/M2 via EX and Wine but remains patchy for recent titles, while M3 GPU acceleration is still missing and driver work has only reached rendering a triangle.

### Just how far can the FOR UPDATE SKIP LOCKED Postgres queue go?

The article benchmarks a Postgres-backed job queue using `FOR UPDATE SKIP LOCKED` on a 1-CPU instance. With 64 workers each using its own connection, throughput peaked around 375 jobs/s and CPU saturated before the default 100-connection limit. Using a shared pool of 20 connections let 128 workers reach about 650 jobs/s.

- [Just how far can the FOR UPDATE SKIP LOCKED Postgres queue go?](https://garbagecollected.io/posts/postgres-task-queue-where-it-breaks/) — *garbagecollected.io*
