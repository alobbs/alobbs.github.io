### Brave Search API now accepts agentic payments via the x402 protocol

Brave Search API now supports instant, pay-as-you-go agentic payments via the open x402 protocol, allowing developers and autonomous AI agents to query Brave’s search index and settle requests in real time without traditional API key management. Requests without payment receive an HTTP 402 response with pricing and payment details; agents can pay in USDC on the Base blockchain and retry with a signed payment. Brave says pricing follows published API rates at $0.005 per request ($5 per 1,000) for LLM Context and other endpoints.
