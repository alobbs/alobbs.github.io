### Linux 7.4 Sound Changes Merged: "The AI Flood Continues"

Linux 7.4 sound subsystem changes have been merged, with maintainer Takashi Iwai noting that the “AI flood continues” as AI/LLM agents keep producing many patches and uncovering kernel bugs. The cycle includes ALSA core hardening and race fixes, deprecation of OSS sequencer emulation, and new hardware support such as Intel Tigerlake+ SOF IPC4 compressed playback and AMD ACP 7.0/7.F for upcoming Zen 6 platforms. It also adds laptop quirks and new codec drivers from ESS, Nuvoton, Senary, and Qualcomm.

### Realtek rtl8723bs Driver Deleted From Staging Area In Linux 7.4

The Realtek rtl8723bs driver has been deleted from the Linux kernel’s staging area after nearly a decade. Its 802.11 b/g/n SDIO WiFi/WLAN and Bluetooth support is now handled by the more mature RTW88 driver in the Linux networking subsystem.

### Google's C Binder Driver Removed With Rust Binder Ready For "Few Billion Devices"

Linus Torvalds merged char/misc changes for the Linux 7.4 kernel that remove Google’s C-written Binder driver. The Rust Binder driver has matured to feature parity, outperforms the C driver in some tests, and is now Google’s sole focus for Android IPC. Greg Kroah-Hartman said the stable Rust Binder will be used going forward in a few billion devices.

- [Google's C Binder Driver Removed With Rust Binder Ready For "Few Billion Devices"](https://www.phoronix.com/news/Linux-7.4-Char-Misc) — *phoronix.com*

### When a glibc update accidentally breaks Chromium's audio (2021)

In 2021, a glibc update broke Chromium’s YouTube playback when glibc aborted after its futex facility returned an unexpected error. The failure was traced to Chromium’s BPF sandbox rejecting a futex syscall with a custom error code that glibc treated as fatal.

## 🔒 Security & Dev Tools

### POSIX wordexp(3) is dangerous

The POSIX `wordexp(3)` API enables shell-style command expansion by default, making it dangerous. Passing `WRDE_NOCMD` is not reliably safe because implementations such as musl and macOS delegate to a shell and have had bypasses. It should not be used on untrusted inputs, even with that flag.

- [POSIX wordexp(3) is dangerous](https://yossarian.net/til/post/posix-wordexp-3-is-dangerous/) — *yossarian.net*

### Partial Order Precedence

Zig has implemented its second-oldest open proposal, issue #114, requiring parentheses for ambiguous operator precedence combinations in the master branch, thanks to contributor CMDRZero. The compiler now rejects expressions where precedence is undefined, while common cases like arithmetic remain parenthesis-free. The change affected only 353 lines in Zig’s million-plus-line codebase.

- [Partial Order Precedence](https://ziglang.org/devlog/2026/#2026-10-24) — *ziglang.org*

### Farol – a risk map of a pull request for the person who approves it

Farol is a free, open-source CLI and GitHub Action that runs after AI review to assess how risky a pull request is to merge and which files carry that risk. Using static analysis, it provides a verdict and 0–100 risk score based on reach, diff coverage, security findings, contract breaks, and dependency changes, then highlights the riskiest files first. The goal is to focus reviewer attention so low-risk pull requests move quickly while risky changes get closer, line-by-line scrutiny.

- [Farol – a risk map of a pull request for the person who approves it](https://github.com/winnin/farol) — *github.com*
