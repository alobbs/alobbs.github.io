### Indirect Calling of Nested Functions on GCC Without Executable Stack

The article presents a hack for older GCC versions to avoid executable stacks when using nested functions: instead of invoking the trampoline directly, extract the code address and static chain from it and call the nested function via `__builtin_call_with_static_chain`, then use `patchelf` to clear the executable stack flag. It also notes the downside that a trampoline is still created and the call is not devirtualized, but the stack can be made non-executable afterward.

### Samsung's Processing-in-Memory (PIM)
