### Any long password will do: SSH flaw lets hackers into Alpine systems, routers and more

A decade-old SSH flaw allows attackers to bypass login checks on Alpine Linux and other systems using the musl library by entering any password between 257 and 1024 characters. The vulnerability mainly affects accounts without passwords, including root, and can be exploited by anyone with network access to the SSH port. Administrators should update OpenSSH, restart the SSH service, or disable password logins until patched.

- [Any long password will do: SSH flaw lets hackers into Alpine systems, routers and more](https://cybernews.com/security/openssh-password-authentication-bypass-flaw-alpine-musl-systems/) — *cybernews.com*

### MoofTCP – A modern replacement for MacTCP on 68k Macs

### Kugelblitz – Mac-Native Google Earth Alternative

It offers a library of global map services, 3D buildings, smooth navigation even on M1 Macs, and optional Vision Pro viewing without a headset app. No account is required, and loaded map data is cached and can be shared across instances on the same network.
