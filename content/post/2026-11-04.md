### Nvidia DGX Spark encrypted firmware slows inference speed to 35% on Linux

Linux dual-boots on Nvidia RTX Spark laptops, but a Windows-only encrypted power-management firmware locks the GPU to about 780 MHz when plugged in, cutting GPT-OSS-120B inference to 13.9 tokens/s versus 65.4 on Windows. WSL currently avoids the throttling and keeps full GPU boost, while a native Linux fix depends on Nvidia porting its platform-controller power logic into the Linux driver.

### Osewa – An open-source alternative to SSH and Mosh

Osewa is an open-source terminal protocol positioned as an alternative to SSH and Mosh, designed for long-running agent sessions that can be accessed from laptops or phones across changing networks. It keeps each session on the host using Ghostty’s engine, supports QUIC or TCP with automatic fallback, and preserves the PTY, screen state, and unacknowledged input while prioritizing keystrokes over bulk data.

- [Osewa – An open-source alternative to SSH and Mosh](https://osewa.dev/) — *osewa.dev*

### Milkman – The Better Alternative to Postman
