### 9-Bit AES Key Case

Several PDF implementations that advertise AES-256 generate file keys from small or insecure random state spaces, enabling passwordless decryption. MuPDF’s AES-256 key depends on only 9 bits of random state, while Foxit uses time-based randomness, making keys trivial to recover.

- [The case of the 9 bit AES key](https://v12.sh/blog/the-case-of-the-9bit-aes-key) — *v12.sh*

### Newly discovered Kerberos delegation abuse path

### Sleep framework: A new way for LLMs to retain knowledge in continual learning

Google researchers propose a “sleep” framework for continual learning in LLMs that adds offline memory consolidation phases to help models integrate new facts and improve reasoning without catastrophic forgetting or fixed knowledge cutoffs. It reportedly enables retention of long-context knowledge up to 10 million tokens while keeping the model architecture unchanged.
