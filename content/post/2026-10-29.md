### Keplearn: Extract Equations from Data in Seconds

Keplearn is a deterministic Rust-based symbolic regression engine that recovers closed-form equations from tabular CSV/TSV data by best-first recursive reduction, inspired by Kepler’s derivation of planetary laws. ### Capo-S3 – a typed, async-first S3 client for Python

capo-s3 is a typed, async-first Python SDK for Amazon S3 and S3-compatible storage such as RustFS, MinIO, and Cloudflare R2. It provides asyncio/trio support via AsyncS3Client and a matching synchronous S3Client, with TypedDict-typed requests and responses. It also includes multipart transfer management, presigned URLs and POST forms, paginators, and waiters, and is part of the capo alternative to boto3/aioboto3 built on its own HTTP stack.

### Overtone – Transcribe, correct and cut captions for any screen shape

Lont has open-sourced Overtone, an MIT-licensed tool that transcribes, corrects, and formats video captions for any screen shape. It combines multiple speech-to-text models with an LLM to resolve conflicting transcriptions and reduce word errors, then uses a rules-based cutter to create layout-appropriate captions. Overtone costs more due to multiple models but aims to minimize manual caption fixes, and includes a Video.js plugin, burn-in support, and a CLI.
