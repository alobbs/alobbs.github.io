### Jeff – Jev-compatible 0.8B decision models, trained at home, ~30 ms

Jeff is a family of Jev-compatible 0.8B and 2B decision models fine-tuned from Qwen3.5 and Gemma 4 for zero-shot classification, returning calibrated probabilities for user-specified options in a single forward pass. It runs at roughly 22 ms per decision on an RTX PRO 6000 and 28 ms on an Apple M4 Max, and was trained entirely on local hardware using synthetic data generated by an open model. It is an independent project using the same request format as Jev, with models available on Hugging Face and optional fine-tuning for higher accuracy.

- [Jeff – Jev-compatible 0.8B decision models, trained at home, ~30 ms](https://github.com/firelex/jeff) — *github.com*

### Nvidia launches AI agent safety platform

Nvidia has launched its Open Agent Safety Platform, a reference design to monitor and contain autonomous AI agents in real time. It combines OpenShell, an Apache 2.0 secure runtime that runs on CPUs to sandbox and limit agents’ access to files, networks, apps, and resources, with Sentry, a BlueField-4 DPU-based watchdog that can quarantine or stop rogue agents in milliseconds. The launch follows reported AI-agent breaches and escapes, including the July Hugging Face/OpenAI incident and a Medicare portal hack, and has drawn more than 100 partners including Anthropic, Microsoft, Cisco, Oracle, Dell, HPE, Lenovo, Arm, and Intel, coinciding with Nvidia’s roughly $13 billion acquisition of Hugging Face.

### OpenAPPA – open-source deterministic guardrails that don't break agents

OpenAPPA is an open-source deterministic guardrail system for AI agents designed to prevent data leaks without sacrificing agent utility. It uses a data-specific rather than use-case-specific policy language and adds mechanisms such as remedy plans and a DualLLM pattern, reportedly raising utility from about 40% to 90%. It is pluggable into any agent loop via pre- and post-tool-call hooks, with benchmarks and an academic paper available.

- [OpenAPPA – open-source deterministic guardrails that don't break agents](https://www.openappa.com/) — *openappa.com*
