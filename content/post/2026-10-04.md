### Improving and Stabilizing the racoon2 IKE Daemon in NetBSD

Artem Belan’s Google Summer of Code 2026 project improved and stabilized the racoon2 IKE daemon in NetBSD, making it more reliable for L2TP/IPsec and IKEv2 VPN use. The work implemented RFC 7383 IKE fragmentation, RFC 3947 NAT-OA payloads in IKEv1 Quick Mode, better IPv6 support, address-macro cleanup, and an automated unit test framework. The changes were developed on the gsoc2026 branch and merged upstream through pull requests #13–#39 from June to September 2026.

### Linux Begins Seeing Workarounds For Fujitsu MONAKA CPU Bugs

Fujitsu has announced MONAKA, a 144-core Arm-based server CPU for AI infrastructure, and Linux kernel patches are now adding CPU detection and workarounds for its bugs. MONAKA Linux support is otherwise largely mature as a standards-compliant ARM64 server design.
