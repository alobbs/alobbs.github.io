### Serokell’s Work on GHC: Dependent Types, Part 5

The article reports progress on Dependent Haskell, highlighting three major contributions: visible `forall` in GADTs, namespace-specified imports, and type instances in kind checking. ### The Free Lunch Is Over: A Fundamental Turn Toward Concurrency in Software (2005)

Historically, CPU performance improvements came from increasing clock speed, optimizing instruction execution (including aggressive reordering that can break program semantics), and expanding on-chip cache—all concurrency-agnostic gains that benefit sequential and concurrent programs alike. However, only cache size increases are expected to continue in the near term, signaling the end of "free lunch" performance scaling and a shift toward concurrency for continued speedups.

- [The Free Lunch Is Over: A Fundamental Turn Toward Concurrency in Software (2005)](http://www.gotw.ca/publications/concurrency-ddj.htm) — *gotw.ca*

### nixpkgs-multiverse: fast mode

nixpkgs-multiverse now offers a "fast" mode that provides direct store paths for every indexed historical version of Nixpkgs packages, letting users build or run them without downloading or evaluating the full Nixpkgs tree. It works by combining historical Hydra build listings with a version index and using `builtins.appendContext` to create fake derivations that bypass Nix's usual evaluation requirements.

### Demystifying Type (and some Un-Paradoxing)

### Using GCC's Nested Functions with Wide Pointers and No Trampolines II

GCC 16 guarantees that nested functions not accessing parent variables avoid stack trampolines, improving security and allowing such functions to be safely returned. A recently merged GCC patch adds built-ins like `__builtin_call_with_static_chain` to remove trampolines even for capturing nested functions, with wide pointer types offering cleaner syntax and efficient code generation.
