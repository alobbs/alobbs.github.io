## 💻 OS & Hardware

### Linux 7.4 To Land New BTB CTX Isolation Feature Of AMD Zen 6

Linux 7.4 is expected to add support for AMD Zen 6's new Branch Target Buffer Context (BTB CTX) Isolation feature. This security defense isolates user/kernel and guest/host contexts to help mitigate the SRSO vulnerability that affected Zen 1 through Zen 4 CPUs. A patch queued in tip.git's x86/bugs branch is set to be submitted for Linux 7.4, which is shaping up as an important release for Zen 6 enablement.

- [Linux 7.4 To Land New BTB CTX Isolation Feature Of AMD Zen 6](https://www.phoronix.com/news/AMD-Zen-6-BTB-CTX-Linux-7.4) — *phoronix.com*

### Linux's ZRAM Reworked For Greater Memory Savings, Better Performance

Google's Sergey Senozhatsky has proposed a major ZRAM rework for the Linux kernel to improve memory savings and performance. The patches reportedly save double-digit to triple-digit kilobytes per context and CPU, while splitting Zcomp backend read and write streams reduces blocking and improves performance. The series also reworks secondary compression streams for further memory savings and is now under review on the Linux kernel mailing list.

- [Linux's ZRAM Reworked For Greater Memory Savings, Better Performance](https://www.phoronix.com/news/Linux-ZRAM-Rework-Savings) — *phoronix.com*

### Linux 7.4 To Mainline Support For The Google Tensor G5, Pixel 10 Devices

Linux 7.4 is set to mainline support for Google's Tensor G5 SoC and Pixel 10 devices. The pull request introduces the new ARCH_GOOGLE architecture, Tensor G5 SoC family support, and initial Device Trees for the Pixel 10, Pixel 10 Pro, and Pixel 10 Pro XL. Tensor G5 includes Cortex-X4, Cortex-A725, and Cortex-A520 cores, Imagination PowerVR graphics, LPDDR5X memory, and a 4th Gen TPU.

- [Linux 7.4 To Mainline Support For The Google Tensor G5, Pixel 10 Devices](https://www.phoronix.com/news/Linux-7.4-Google-Tensor-G5) — *phoronix.com*

### Linux 7.4 Continues Preparing For Intel's Rugged Panther Lake

Linux 7.4 is adding further enablement for Intel’s Rugged Panther Lake (Panther Lake R), a ruggedized variant believed to be the Starfire SoC. The patches add support across intel-uncore-freq, Intel PMC, intel_tcc_cooling, and turbostat, mostly by adding the PANTHERLAKE_R device ID. Linux 7.4 is expected to become the baseline for Rugged Panther Lake/Starfire due to power-management requirements.

- [Linux 7.4 Continues Preparing For Intel's Rugged Panther Lake](https://www.phoronix.com/news/Linux-7.4-Rugged-Panther-Lake) — *phoronix.com*

### Qualcomm Patching Linux For Hardware Thermal Binning To Benefit Snapdragon X Laptops

Qualcomm has submitted Linux kernel patches to add hardware thermal binning support, allowing the OS to properly account for different junction temperature limits in otherwise identical Qualcomm SoCs. The support is aimed at benefiting Snapdragon X laptops, including the Snapdragon X1 Elite (X1E80100) and newer chips, by reading manufacturing fuses to identify each silicon's thermal bin. The patches are currently out for review on the Linux kernel mailing list.

- [Qualcomm Patching Linux For Hardware Thermal Binning To Benefit Snapdragon X Laptops](https://www.phoronix.com/news/Qualcomm-HW-BIn-Trip-Point) — *phoronix.com*
