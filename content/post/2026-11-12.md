### Polo Debuts As New Wayland Compositor For MATE Desktop

Polo 1.0 has been released as a new Wayland compositor for the MATE desktop. It aims to replicate MATE’s X11 behavior using Marco’s window-management policies, settings, and themes while building on Weston, with XWayland support. Developed by MATE user Kerem Söke, Polo also supports GNOME 2-style effects such as the desktop cube and wobbly windows.

### Porting my Electron app to Rust: 675 MB to 91 MB

Jot, a Mac capture app, was ported from Electron to Rust using the Rune GPU UI framework, reducing its on-disk size from 675 MB to 91 MB and its DMG download from 302 MB to 44 MB. Jot 2.0 preserves the same vault, settings, Keychain items, license, and bundle ID, so existing users can update in place. The Rust rewrite consolidates state and view into one process without IPC, moving OS-specific code into a single module and reusing core note and vault code across the app, CLI, and MCP server.

- [Porting my Electron app to Rust: 675 MB to 91 MB](https://sayjot.xyz/blog/rust-port) — *sayjot.xyz*
