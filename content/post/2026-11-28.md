### A 52 KB WebAssembly engine that runs Qwen3.5-2B in a browser tab

A roughly 52 KB WebAssembly engine runs Qwen3.5-2B/0.8B and older Qwen3 models directly in a browser tab, with weights cached locally and all tokens computed on the CPU without a server, GPU code, or inference API. Written in Zig and using 4-bit GGUF weights, it reaches about 65–75% of native llama.cpp CPU generation speed and includes a no-network Python sandbox for code execution.

### Hackers breach Erlang and Elixir package manager

Hackers breached Hex.pm, the main package manager for Erlang and Elixir, by exploiting a zero-day untrusted deserialization vulnerability (CVE-2026-129514, severity 10/10) to take over six backend servers. Hex.pm fixed the issue within 20 minutes and found no unauthorized changes to packages, but could not rule out user data access because database reads were not logged. The team rotated backend credentials and advised developers to change passwords, reset 2FA, and update Hex clients.

### Earth Stays Above 2°C of Warming for Six Days in a Row

For six consecutive days in late November, global average surface temperatures exceeded 2°C above the preindustrial baseline, the first such run on record, according to Copernicus ERA5 data. The streak peaked on 23 November at a record 2.24°C above the 1850–1900 average. Scientists cautioned that these daily readings do not mean the world has breached the Paris Agreement’s long-term temperature limits.

- [Earth Stays Above 2°C of Warming for Six Days in a Row](https://www.natureworldnews.com/articles/74096/20261126/earth-stays-above-2c-warming-six-days-row-first-time-copernicus-data-show.htm) — *natureworldnews.com*

### Stigler Diet

The Stigler diet is an optimization problem posed by economist George Stigler asking how a 154-pound man could meet nine 1943 recommended nutrient allowances at minimal cost using 77 foods. His solution used only wheat flour, evaporated milk, cabbage, spinach, and dried navy beans, costing about $0.11 a day in 1939 dollars. Though criticized for poor variety and palatability, the work is praised as an early application of linear programming.

- [Stigler Diet](https://en.wikipedia.org/wiki/Stigler_diet) — *en.wikipedia.org*
