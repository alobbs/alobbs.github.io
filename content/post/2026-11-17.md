### How the Claude Code team thinks about verification

### Pulsar – cross-harness agent to agent communication and messaging

Pulsar is an MCP server that connects AI coding agents across harnesses—including Claude Code, Codex, OpenCode, pi, omp, Cursor, and Gemini CLI—on one local message bus. After `npx pulsar setup`, agents can discover, tag, and message each other individually, by selector, or in groups, with push delivery that can wake idle agents and support request/reply threads. It is safe by default and has no telemetry, with cross-machine messaging and remote control via Tailscale coming soon.

- [Pulsar – cross-harness agent to agent communication and messaging](https://github.com/yocontra/pulsar) — *github.com*
