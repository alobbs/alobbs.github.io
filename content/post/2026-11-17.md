### Program-as-Weights: A Programming Paradigm for Fuzzy Functions

The paper proposes “fuzzy-function programming,” compiling natural-language specifications for tasks unsuited to rule-based code into compact, locally executable neural artifacts. Its Program-as-Weights (PAW) method uses a 4B compiler trained on the released FuzzyBench dataset to generate parameter-efficient adapters for a frozen lightweight interpreter. A 0.6B Qwen3 interpreter running PAW programs matches direct prompting of Qwen3-32B while using about one-fiftieth the inference memory and running at 30 tokens/s on a MacBook M3.

## 🔒 Security & Privacy

### Critical Red Hat Quay flaw lets attackers read and overwrite all private container images

Red Hat disclosed a critical Quay flaw, CVE-2026-123710 (CVSS 9.8), that lets an attacker who can reach a registry add a trusted signing key and use it to read or overwrite private container images in every repository; fixed builds cover eight Quay 3 branches. A second critical flaw, CVE-2026-110697 (CVSS 9.9), lets a user who can create a namespace steal other tenants’ robot-account tokens and use them to access or modify their images. Red Hat lists all Quay 3 and Quay 5 versions as affected, including standalone, Operator, and OpenShift mirror registry deployments.

- [Critical Red Hat Quay flaw lets attackers read and overwrite all private container images](https://thehackernews.com/2026/11/critical-red-hat-quay-flaw-lets.html) — *thehackernews.com*
