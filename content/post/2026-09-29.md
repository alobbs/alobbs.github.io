### Jevstiller distills Jev for local use

Jevstiller is an open-source local CPU tool that distills Jev’s answers, enabling responses in about 15 ms instead of Jev’s roughly 300 ms network calls while routing uncertain or out-of-distribution requests back to Jev. It uses a frozen sentence encoder, logistic regression head, OOD scorer, and calibrated confidence threshold to uphold a user-set agreement bound, such as 98%, and is retrained every 2,000 new Jev answers, versioned, and shadow-tested before promotion.

- [Jevstiller – Distill Jev into a local model, with a disagreement bound](https://jevstiller.pages.dev/posts/the-guarantee/) — *jevstiller.pages.dev*

### Jeeves. Reasoning improves Jev-like decision models

Jeeves is a 9B reasoning Jev-style decision model built on Qwen3.5-9B with LoRA and a pointer head, using a block-4 diffusion drafter and trained with SFT and CISPO. It outperforms Kev-9B and Jev on held-out test data (0.889 vs 0.822 and 0.857) and on JevBench’s public tiers (0.935 vs 0.866 for Jev), while supporting yes/no, multiple-choice, and rating questions via a Jev-compatible API. On one H100, it takes about 0.3 seconds per request without thinking and a 3.3-second median with thinking.

- [Jeeves. Reasoning improves Jev-like decision models](https://github.com/PostHog/jeeves) — *github.com*

### Branch Target Reuse, BTR: New Spectre V2 Attack Targeting JIT Compilers

VUSec researchers have disclosed Branch Target Reuse (BTR), a new Spectre V2 attack targeting JIT compilers in Linux kernel BPF, Oracle GraalVM, and Mozilla SpiderMonkey/Firefox.
