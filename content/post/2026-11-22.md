## 🐧 Linux Kernel & Hardware

### Linux 7.5 To Introduce Initial Mainline Support For Ambarella SoCs

Linux 7.5 will introduce initial mainline support for Ambarella SoCs, with the CV75 as the first target. The patches add the ARCH_AMBARELLA Kconfig, Device Tree support, and EVK developer board support, contributed directly by Ambarella. The CV75 is a 5nm Arm Cortex-A76-based SoC for computer vision, image signal processing, and low-power video applications.

- [Linux 7.5 To Introduce Initial Mainline Support For Ambarella SoCs](https://www.phoronix.com/news/Linux-7.5-Ambarella-SoCs) — *phoronix.com*

### PSR2 & Panel Replay + Pipe Joiner To Be Supported For Intel On Linux 7.5

Intel’s Linux 7.5 graphics driver will support PSR2 and Panel Replay when using pipe joiner functionality, enabling power savings alongside multi-pipe configurations for high-resolution or high-refresh displays. The change was submitted to DRM-Next via the drm-intel-next pull request, which also includes code cleanups, IRQ handler optimizations, and driver fixes.

- [PSR2 & Panel Replay + Pipe Joiner To Be Supported For Intel On Linux 7.5](https://www.phoronix.com/news/Intel-PSR2-Panel-Replay-Joiner) — *phoronix.com*

### The First Rust WMI Linux Driver Being Developed Is For Clevo Laptops

Nick Dowsett has announced "clevo-laptop," the first Rust-based Linux WMI driver, targeting Clevo laptops sold by TUXEDO Computers, Metabox, Sager, XMG, and others. It aims to be the first in-tree user of the kernel’s Rust WMI abstractions and initially supports 5-stop white keyboard backlight control. The preliminary driver is under 400 lines of Rust and depends on yet-to-be-merged WMI and LED abstractions for Rust.

- [The First Rust WMI Linux Driver Being Developed Is For Clevo Laptops](https://www.phoronix.com/news/Rust-WMI-Driver-Clevo-Laptops) — *phoronix.com*

### Linux 7.4 To Remove NVMe Namespaces In Parallel For Faster Results

Linux 7.4 will remove NVMe namespaces in parallel, speeding up removal compared with the previous one-at-a-time approach. The optimization, part of this week’s block subsystem fixes for 7.4-rc4, was merged via the block pull request and is useful for multi-tenant and complex server deployments.

- [Linux 7.4 To Remove NVMe Namespaces In Parallel For Faster Results](https://www.phoronix.com/news/Linux-7.4-NVMe-NS-Parallel) — *phoronix.com*

### Harsher on Male? Evaluating LLMs on Gender-Asymmetric Moral Framing in Conflicts

The paper introduces GAMA-Bench, a gender-mirrored benchmark of 1,298 conflict scenarios, to test whether LLMs respond consistently to the same negative behavior by male and female actors. Across 10 representative LLMs, it finds a consistent male-disadvantaging asymmetry: male actors receive more punitive, escalatory, and blame-centered framing, while female actors receive more therapeutic and empathy-oriented framing. This pattern persists across model families, scenario tracks, model scale, and explicit reasoning styles.

- [Harsher on Male? Evaluating LLMs on Gender-Asymmetric Moral Framing in Conflicts](https://arxiv.org/abs/2606.14068) — *arxiv.org*
