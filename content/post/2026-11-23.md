### What we learned operating auth for 1k APIs

### XNU Linux: Full OS X GUI Userspace on Linux

xnulinux runs macOS userspace on Linux by building Apple’s open-source XNU kernel and loading it as a kernel module inside an unmodified arm64 Linux kernel. The hosted XNU drives the CPU and MMU directly, letting macOS and Linux processes run natively side by side without a hypervisor while Linux supplies memory, timers, files, networking, and GPU access through interface modules. With a stock Ubuntu kernel, it can boot a macOS 27 system disk to the desktop, including loginwindow, WindowServer, Dock, Finder, Safari, and Chrome.
