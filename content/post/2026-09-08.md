### C*: Unifying Programming and Verification in C

C* is a proof-integrated extension of C that embeds verification capabilities, including a symbolic execution engine and LCF-style proof kernel, allowing programmers to interleave proof-code with implementation and update proof state in real time. It uses C as the common language for both programming and proof development, supporting reusable proof libraries and programmable automation. Evaluations on C programs and the pKVM buddy allocator's attach function show it verifies a broad subset of C and handles real-world reasoning tasks.

- [C*: Unifying Programming and Verification in C](https://arxiv.org/abs/2504.02246) — *arxiv.org*
