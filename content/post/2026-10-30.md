### Startups bet AI can make formal software verification practical; &Truth launches with $70M seed

A wave of startups is betting that generative AI can make formal software verification—math-based proof that code works as intended—practical and widespread. &Truth launched Thursday with a $70 million seed round and aims to eventually verify any programming language, building on research that used AI to verify part of Signal’s encryption code. Rivals including Harmonic and a Theorem-Anthropic collaboration are also advancing AI verification tools, though the technology remains in prototyping and questions about pricing and adoption persist.

### Trojanized Claude Code Extension Plants an SSH Backdoor

The Claude Code extension version 2.1.313 in the Cursor Marketplace was compromised with a malicious 66-line loader inserted before the legitimate extension code. When activated, it adds an attacker-controlled SSH key, attempts to enable local SSH, establishes a reverse tunnel to 134.209.82.225, installs platform-specific persistence, and sends host reconnaissance over unencrypted HTTP. The @anthropic-ai/claude-code NPM package, OpenVSX extension, and Microsoft VS Code extension were reported not malicious.

- [Trojanized Claude Code Extension Plants an SSH Backdoor](https://opensourcemalware.com/blog/trojanized-claude-code-extension-plants-persistent-ssh-backdoor) — *opensourcemalware.com*

### How curl was accidentally Turing-complete for nine months

From curl 8.12 through 8.16, config files could slice variable values and include other config files without an explicit depth cap, allowing curl to simulate any two-counter Minsky program and, under idealizations of unbounded strings and resources, be Turing-complete. Curl 8.17.0 added a five-level include cap that breaks this reduction.

- [How curl was accidentally Turing-complete for nine months](https://seriot.ch/computation/curl.html) — *seriot.ch*

## 🖥️ Systems & Hardware

### arm64e pointer authentication: PAC keys, PACIASP, A12

The article explains arm64e pointer authentication, in which a cryptographic PAC is stored in unused pointer bits and verified by hardware at branch time against a key not held in memory. It covers the PAC field layout, including a measured 16-bit instruction-pointer field on a stock Mac and a cited 24-bit kernel-pointer mask on A12. Because direct reads and writes cannot recover the key, the analysis focuses on the modifier, signing operation, or crash behavior, with no exploit chain presented.

- [arm64e pointer authentication: PAC keys, PACIASP, A12](https://sigreturn.com/blog/pointer-authentication-arm64e/) — *sigreturn.com*

### AMD PerfOpt Makes it Into Linux 7.4 As A Nice Performance Boost For AMD iGPUs

AMD PerfOpt has been merged into the Linux 7.4 kernel, allowing AMD Radeon iGPUs to bypass the IOMMU for direct system-memory access and enabling it by default in the AMDGPU driver. Benchmarks show notable performance gains, especially for AI workloads, including 18–23% boosts for Radeon iGPUs and improvements for prior-gen Ryzen APUs; users can verify activation via dmesg.

- [AMD PerfOpt Makes it Into Linux 7.4 As A Nice Performance Boost For AMD iGPUs](https://www.phoronix.com/news/Linux-7.4-IOMMU) — *phoronix.com*
