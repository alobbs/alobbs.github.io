### arm64e pointer authentication: PAC keys, PACIASP, A12

The article explains arm64e pointer authentication, in which a cryptographic PAC is stored in unused pointer bits and verified by hardware at branch time against a key not held in memory. ### Go programs enable MPTCP by default, exposing them to Linux CVE-2026-98432

CVE-2026-98432 is a Linux kernel IPv4 TCP use-after-free that can enable RCE, with a demonstrated exploit requiring an MPTCP listener, though the underlying bug is not MPTCP-specific; upgrading to a patched kernel is the recommended fix. Go 1.24 enables MPTCP by default for Linux listen sockets, and programs can disable it via `GODEBUG=multipathtcp=0`, `godebug multipathtcp=0` in `go.mod`, or per-socket `SetMultipathTCP` methods. The Go Security Team warns that per-program MPTCP disabling is a fragile mitigation and says it is premature to change Go’s defaults, with further discussion at go.dev/issue/82717.

- [Go programs enable MPTCP by default, exposing them to Linux CVE-2026-98432](https://groups.google.com/g/golang-announce/c/PCoQcdxoScw) — *groups.google.com*

### Curl accidentally Turing-complete for nine months

From curl 8.12 through 8.16, config files could slice variable values and include other config files without an explicit depth cap, allowing simulation of any two-counter Minsky program and, under unbounded-resource idealization, accidental Turing completeness. Curl 8.17.0 added a five-level include cap that breaks this reduction, while real binaries remained bounded by memory, stack, and expansion limits.
