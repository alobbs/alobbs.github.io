### Unexpected (to me) behaviour in Lisp sub-typing

In Common Lisp (SBCL), literal array syntax like `#1A(1 2 3)` is typed as `simple-vector`, which is not a subtype of specialized arrays like `(simple-array (unsigned-byte 16))`, causing type errors. This stems from upgraded array element types, where unconstrained types upgrade to `T` but fixed-width types like `(unsigned-byte 16)` do not. The workaround is to explicitly create arrays with `make-array` and specify the intended element type.
