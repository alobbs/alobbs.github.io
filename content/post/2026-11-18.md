## 🔐 Security & Cybercrime

### Nginx HTTP/2 Pre-Auth RCE

Researchers found five independent unauthenticated remote code execution vulnerabilities in nginx affecting different configurations, plus a Linux kernel SCTP flaw that can be chained to gain root and escape containers. The most impactful nginx flaw, CVE-2026-123007—one of two critical HTTP/2 RCEs (with CVE-2026-123633) independently discovered by Wiz Research and others and rated CVSS 4.0 9.2—affects HTTP/2-enabled nginx 1.9.5 through 1.31.8 and allows command execution with worker privileges; because the flaws are in nginx itself, secure application code does not protect affected servers. Users should update to nginx 1.31.9 when available following the coordinated November 18 release, and note that disabling HTTP/2 blocks only CVE-2026-123007 and CVE-2026-123633, not the other three nginx vulnerabilities.

### Energy-Based Reasoners for Efficient Inference

Researchers introduced Energy-Based Reasoners (EBRs), recurrent models that learn an energy function over latent reasoning states and use gradient descent/looped updates to score, refine, stop, and select predictions without an external verifier. With 1.8M parameters, EBRs report 99.9% accuracy on Sudoku-Extreme using 345× less inference compute than the next-best model (one headline cites 385×). They also achieve state-of-the-art solution coverage with near-100% single-sample accuracy on N-Queens and Graph Coloring.

### Classical Energies Learn to Reason 1k× Faster Than Looped Models

Researchers introduce CRAM, a learned energy-based model inspired by Hopfield & Tank, which solves 99.996% of Sudoku-Extreme and 100% of Maze-Unique test puzzles after only 42 ms and 132 ms of training on one GPU—at least 1,000× faster than looped models. CRAM also matches baseline looped models’ highest Sudoku-Extreme accuracy using at least 282× fewer inference FLOPs. The authors argue energy-based training is promising for reasoning but caution against using trivially solvable benchmarks like Sudoku and Maze to test looped reasoning scalability.

- [Classical Energies Learn to Reason 1k× Faster Than Looped Models](https://arxiv.org/abs/2611.17309) — *arxiv.org*

### Why is Gemini 4 Carbon taking so long?

The average household now has 24 smart devices connected to its network, according to Bitdefender and Netgear, with TVs, smart plugs, and network-attached storage posing many of the biggest security risks. Most exploited vulnerabilities are already known and fixed, so regular updates and replacing unsupported devices can reduce risk. Smart TVs can also collect viewing and household data for targeted advertising.
