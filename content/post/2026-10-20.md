### AMD GAIA 0.25 Brings Several Improvements For Local AI Agents On Ryzen AI

AMD has released GAIA 0.25, an update to its open-source project for building and using local AI agents on Ryzen AI hardware. ### Make AI coding agents verify its own work

Reticle is a dev-only SDK and toolset that lets AI coding agents verify changes by driving the running app, observing requests, responses, state, console output, and source lines, then returning a pass/fail/cannot-tell verdict with `file:line` evidence. It addresses coding agents’ tendency to assume success without opening the app, which can let broken UI, silent errors, and failed deploys ship. In a demo, an agent claimed a fix worked while Reticle caught a double charge and named the responsible source line.
