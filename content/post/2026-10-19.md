### Strot – Compile an LLM's intent once, run decisions locally forever

Strot is an open-source decision compiler that uses an LLM once at compile time to translate intent and sample data into a frozen, self-contained Python artifact. It then makes classification, scoring, routing, and typed-answer decisions locally on CPU for every record, returning type-safe JSON with probabilities and confidence at zero marginal cost. Low-confidence cases abstain, and the package is available via `pip install strot-ai`.
