macOS Userspace Runs on Linux

XNU Linux is an open-source project that runs macOS userspace natively on Linux by loading Apple’s open-source XNU kernel as a loadable module inside an unmodified arm64 Linux kernel, without a hypervisor. The hosted XNU drives the CPU and MMU directly, letting macOS and Linux processes run side by side while Linux supplies memory, timers, files, networking, and GPU access through interface modules. Tested only on ARM64 with macOS 27 userspace, it can boot a stock Ubuntu kernel to a macOS desktop including loginwindow, WindowServer, Dock, Finder, Safari, and Chrome, though users must obtain macOS binaries themselves.

A short history of read streams in Postgres

The article traces Postgres read-combining from 2007 proposals to Thomas Munro’s Postgres 17 read streams, which use preadv to merge adjacent 8 KiB blocks into larger I/Os, with io_combine_limit in Postgres 18. It highlights that if a page in the middle of a range is already in shared buffers, Postgres splits the combined read around it, and alternating cached pages can force many separate 8 KiB reads. It distinguishes read combining, which reduces requests, from asynchronous I/O, which keeps reads in flight.

  • A short history of read streams in Postgres — frn.sh
