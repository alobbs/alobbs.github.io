Maple – Sub-2-BPW Moe Pruning to Run Gemma 4 26B at 45 TPS on a 6GB GPU

Aman Sachan released MAPLE, a manifold-activated pruning method for mixture-of-experts LLMs that compresses Gemma 4 26B-A4B from 9.92 GB to a 4.75 GB GGUF container at sub-2 bits per parameter. The pruned model targets Python programming, algorithm synthesis, data structures, and formal STEM reasoning by removing 80 dormant multilingual and general conversational experts while retaining 48 active experts. It enables 100% in-VRAM execution on 6 GB GPUs with 45.4 tokens/second throughput.

Nspawn 3.0: A Docker-compatible Engine API for systemd-nspawn containers

Nspawn 3.0 adds a Docker-compatible Engine API for systemd-nspawn containers, extending the earlier read-only API by serving it on the host as well. It includes IPv6 port publishing, compose fixes, image digest validation, apt/rpm packaging, dynamic host ports, platform-aware pulls, and exposes /run/nspawn/api.sock for tools using DOCKER_HOST. The socket is disabled by default and access is governed by existing org.nspawn polkit actions.

  • Nspawn 3.0: A Docker-compatible Engine API for systemd-nspawn containers — blog.nspawn.org

AMD PerfOpt Performance Boosting Code Tweaked For Linux 7.4-rc2

Linux 7.4-rc2 includes tweaks to AMD PerfOpt, which lets AMD SoC integrated Radeon GPUs bypass the IOMMU for direct system memory access and is enabled by default in the AMDGPU driver. The changes move PerfOpt enablement into IOMMU domain attachment paths, remove the amdgpu.iommu_perfopt module parameter, and adjust initialization, suspend/resume, and failure handling. PerfOpt is intended to improve iGPU performance, especially for AI/LLM workloads, and can also benefit prior-generation hardware.

  • AMD PerfOpt Performance Boosting Code Tweaked For Linux 7.4-rc2 — phoronix.com
