MoofTCP – A modern replacement for MacTCP on 68k Macs

MoofTCP is a memory-lean, drop-in replacement for Apple’s MacTCP on 68k Macs running System 6, implementing the MacTCP driver and name resolver interfaces so existing programs run unchanged. It uses a fresh TCP/IP stack written in portable C and adds its own installer, control panel, DHCP client, and a Lite build that saves about 5 KB by omitting DHCP. It aims for reliability, low latency, and throughput while using no more resident memory than MacTCP.
