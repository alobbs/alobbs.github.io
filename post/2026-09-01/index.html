Coherence and orphan instance rules

Typeclasses enable overloading based on type arguments, with instance resolution sometimes requiring explicit type annotations when types are ambiguous. Coherence is the global property that at most one instance matches any constraint, so the same method with the same type parameters always resolves identically throughout a program. Overlapping instances or incoherent modules violate coherence and can break invariants such as consistent hashing in data structures.
