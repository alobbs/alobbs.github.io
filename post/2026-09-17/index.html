Infinite-Parameter LLMs: Generating and Adapting Weights from Live Data

Researchers propose Infinite-Parameter LLM, an architecture that learns from live interaction by generating feed-forward weights from runtime data using a compact hypernetwork and low-rank modulation of a shared base network. Inspired by Mixture-of-Experts, it maintains an online-updated Bayesian belief over the generator’s latent code so weights are re-derived throughout a session while keeping the stored footprint fixed. The approach aims to amortize compute, free context windows, persist across turns, and generalize better than in-context learning or retrieval.
