🐧 Linux & Hardware

Cheap GameSir Nova Lite Gaming Controller Supported By Linux 7.4

Linux 7.4’s input subsystem changes add support for the cheap GameSir Nova Lite wireless gaming controller via the XPad driver. The patch adds the controller’s device ID alongside existing GameSir controllers, enabling force feedback rumble and other functionality on Linux. The GameSir Nova Lite retails for around $22.

AV2 Video Codec Adoption Talked Up, SVT-AV2 Being Developed

The Alliance for Open Media reports growing industry momentum for the royalty-free AV2 video codec, which is claimed to offer about 30% better compression efficiency than AV1. Google is testing AV2 on YouTube and Chrome, with YouTube AV2 streams expected in early 2027, while Meta plans to use AV2 across Facebook and Instagram. Intel is also developing SVT-AV2, a new CPU-based AV2 encoder.

  • AV2 Video Codec Adoption Talked Up, SVT-AV2 Being Developed — phoronix.com

Realtek rtl8723bs Driver Deleted From Staging Area In Linux 7.4

The Realtek rtl8723bs driver has been deleted from the Linux kernel’s staging area after nearly a decade. Its 802.11 b/g/n SDIO WiFi/WLAN and Bluetooth support is now handled by the more mature RTW88 driver in the Linux networking subsystem.

  • Realtek rtl8723bs Driver Deleted From Staging Area In Linux 7.4 — phoronix.com

AMD 600 Series Chipsets Now Have Temperature Monitoring Support On Linux

Linux 7.4 now supports temperature monitoring for AMD 600 series chipsets, with the patch marked for back-porting to Linux 7.2 and 7.3. The change adds the necessary AMD 600 series PCI IDs to the existing xhci-pci-prom21 driver and was merged as part of the Linux 7.4 USB pull request updates.

  • AMD 600 Series Chipsets Now Have Temperature Monitoring Support On Linux — phoronix.com

Google’s C Binder Driver Removed With Rust Binder Ready For “Few Billion Devices”

Linus Torvalds merged char/misc changes for the Linux 7.4 kernel that remove Google’s C-written Binder driver. The Rust Binder driver has matured to feature parity, outperforms the C driver in some tests, and is now Google’s sole focus for Android IPC. Greg Kroah-Hartman said the stable Rust Binder will be used going forward in a few billion devices.

  • Google’s C Binder Driver Removed With Rust Binder Ready For “Few Billion Devices” — phoronix.com

Linux 7.4 Block Updates Range From Floppy Disk Driver Fixes To Apple M4 NVMe Support

Linux 7.4’s block/storage and IO_uring updates have been merged, spanning fixes for legacy floppy and SWIM drivers to new hardware support. The floppy driver received fixes for a possible stack out-of-bounds issue, a 2017 regression, and data races, while the pull request also adds NVMe support for Apple M4 devices.

  • Linux 7.4 Block Updates Range From Floppy Disk Driver Fixes To Apple M4 NVMe Support — phoronix.com

Five Qwen3.8-27B models match Fable 5 Using GVS5H Harness

On 100 hard LiveCodeBench problems, orchestrated Qwen3.8 Flash Next reached 93.0% pass@1 versus Claude Fable 5’s 90.4% at 9% of the cost, while locally served open-weight Qwen3.8-27B rose from 66.8% to 92.4%, though gains were not universal.

Cerebras Deploys Trillion-Parameter AI Models

Using the ~3-trillion-parameter open-source Kimi K3 as an example, Cerebras calculates a 59-wafer deployment and describes pipelining layers across wafers with activation transfers over RDMA Ethernet at roughly 2 microseconds per hop.
