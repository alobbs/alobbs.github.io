Solo: a .so loader for static Linux binaries

SoLo is a loader that enables fully static musl-linked Linux executables to dynamically load the host’s glibc-based GPU drivers (e.g., Vulkan) at runtime, avoiding containers or a second libc. It implements its own ELF loader and glibc ABI bridge, demonstrated by a static Vulkan compute-shader demo running on AMD, Intel, NVIDIA, and Asahi Linux. The project’s CI validates the loader against over 2,100 host shared objects from popular Debian packages on x86-64 and aarch64.
