EXT4 Lands Optional Buffered IOmap For Significant Performance Win With Large Writes

EXT4 file-system changes have been merged for the Linux 7.4 merge window, including opt-in buffered IOmap support enabled via the buffered_iomap mount option. This feature replaces buffer head usage with the IOmap framework and delivers significant performance gains for large writes, with more modest improvements for reads. Because it does not support online defragmentation, inline data, fsverify, fscrypt, non-extent inodes, or data=journal mode, it is not enabled by default and falls back to the original I/O path when necessary.
