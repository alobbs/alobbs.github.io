Sub-1-Bit LLM Compression via Latent Factorization

The LittleBit project provides official implementations for sub-1-bit LLM compression by factorizing dense weight matrices into low-rank latent factors, binarizing them, and using learned scales to restore magnitude. LittleBit (NeurIPS 2025) targets 1.0 to 0.1 bits per weight, while LittleBit-2 (ICML 2026) adds an opt-in Joint-ITQ initialization (--use_itq) to improve latent geometry alignment without inference overhead. The codebase supports models including OPT, Llama, Phi-4, Qwen, QwQ, and Gemma.
