Critical Linux kernel vulnerability leads to full KVM escape

A critical Linux kernel flaw, dubbed PwnEscape and rated 9.3, allows attackers to escape KVM virtual machines and compromise host servers by sending malformed IPv4 packets from inside a guest. The bug exposes host memory and may permit controlled kernel memory changes, requiring no privileges or user interaction. A kernel fix exists, but not all affected Linux distributions have shipped it yet.

NIST Elliptic Curve Seed Bounty Claimed

An Anthropic team has claimed the NIST elliptic curves seeds bounty after discovering the seeds were generated in 1997–98 using the POSIX drand48 random number generator seeded with the then-current UNIX timestamp, rather than by hashing forgotten English sentences. The team claimed the full bounty on October 15, 2026, and donated it to ISRG, which operates Let’s Encrypt, tripling its value to $36,864. The resolution fills in a piece of cryptographic history and reinforces confidence in the NIST elliptic curves.

37-Year-Old OpenBSD Kernel Bug Exploited

Researchers detailed a local root exploit in OpenBSD stemming from a roughly 37-year-old kernel bug in original BSD sources, where a signed 16-bit shared-memory attachment counter could overflow. By chaining the counter wrap with a race-condition use-after-free and a kernel out-of-bounds write, they achieved privilege escalation without an information-disclosure vulnerability despite KARL, SMAP, and SMEP. The issues were fixed in OpenBSD errata 026 and 018.
