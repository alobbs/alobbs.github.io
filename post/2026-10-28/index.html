Sleep framework: A new way for LLMs to retain knowledge in continual learning

Google researchers propose a “sleep” framework for continual learning in LLMs that adds offline memory consolidation phases to help models integrate new facts and improve reasoning without catastrophic forgetting or fixed knowledge cutoffs. The approach alternates active interaction with sleep stages that consolidate short-term context into long-term parameters using pre-allocated Mixture-of-Experts memory blocks and self-generated practice examples. It reportedly enables retention of long-context knowledge up to 10 million tokens while keeping the model architecture unchanged.
