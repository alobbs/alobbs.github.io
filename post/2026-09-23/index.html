Adaptive Lossless Floating-Point Encoding in Apache Parquet

Apache Parquet has introduced Adaptive Lossless Floating-Point (ALP) encoding, a lightweight scheme for FLOAT/DOUBLE data that offers compression ratios similar to zstd while enabling much faster decompression, random access, and SIMD/GPU-friendly decoding. ALP is best for decimal-like values stored as floating-point but unsuitable for wide-exponent or high-significant-digit data such as vector embeddings, which should continue using PLAIN or BYTE_STREAM_SPLIT with ZSTD. In pre-release benchmarks, ALP decoded about 10x faster and supported thousands-times-faster random access than PLAIN+ZSTD or BYTE_STREAM_SPLIT+ZSTD, with slightly lower compression and slightly faster compression.
