Unix File and Directory Permissions and Modes (2018)

Unix and Linux systems use POSIX-defined file permissions that assign each file a user and group and grant read, write, and execute rights to three user classes. Directories use the same permission bits, but read allows listing names, write allows adding/removing/renaming entries, and execute/search is needed to enter a directory and access file inodes. Search permission is also required on all ancestor directories to reach a file.
