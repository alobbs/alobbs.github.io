Nginx HTTP/2 Pre-Auth RCE

Researchers found five independent unauthenticated remote code execution vulnerabilities in nginx affecting different configurations, plus a Linux kernel SCTP flaw that can be chained to gain root and escape containers. The most impactful nginx flaw, CVE-2026-123007—one of two critical HTTP/2 RCEs (with CVE-2026-123633) independently discovered by Wiz Research and others and rated CVSS 4.0 9.2—affects HTTP/2-enabled nginx 1.9.5 through 1.31.8 and allows command execution with worker privileges; because the flaws are in nginx itself, secure application code does not protect affected servers. Users should update to nginx 1.31.9 when available following the coordinated November 18 release, and note that disabling HTTP/2 blocks only CVE-2026-123007 and CVE-2026-123633, not the other three nginx vulnerabilities.

Classical Energies Learn to Reason 1k× Faster Than Looped Models

Researchers introduce CRAM, a learned energy-based model inspired by Hopfield & Tank, which solves 99.996% of Sudoku-Extreme and 100% of Maze-Unique test puzzles after only 42 ms and 132 ms of training on one GPU—at least 1,000× faster than looped models. The authors argue energy-based training is promising for reasoning but caution against using trivially solvable benchmarks like Sudoku and Maze to test looped reasoning scalability.

RBRD: RAM-Backed Linux Block Driver Written In Rust For Better Safety But Slower Performance

Linux kernel patches introduce RBRD, a RAM-backed block driver written in Rust as a safer alternative to the C-based BRD driver. RBRD avoids simultaneous read/write page copies to prevent undefined behavior, but it is slower: writes incur about a 19% single-thread and 22% eight-thread performance hit, while reads are 2–10% slower. Developers argue the page-integrity and safety benefits justify the performance cost.
