Tsampi BFT: Leaderless One-Round Voting with Parameterized Finality

Tsampi BFT is a leaderless Byzantine fault-tolerant protocol that achieves exact-lineage finality with one vote round per block, using a dual-linked vote chain to preserve endorsement order and require strictly better successors. Finality requires two strict-supermajority vote passes, Q1 and Q2, where Q2 is independently deduplicated and only counts later votes from descendant blocks. Proposal admission can be parameterized separately, but with an unchanged validator set and two-thirds endorsement, genesis reaches finality by Block 3 with a steady one-block lag.
