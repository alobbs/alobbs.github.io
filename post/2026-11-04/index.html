Osewa – An open-source alternative to SSH and Mosh

Osewa is an open-source terminal protocol positioned as an alternative to SSH and Mosh, designed for long-running agent sessions that can be accessed from laptops or phones across changing networks. It keeps each session on the host using Ghostty’s engine, supports QUIC or TCP with automatic fallback, and preserves the PTY, screen state, and unacknowledged input while prioritizing keystrokes over bulk data.

  • Osewa – An open-source alternative to SSH and Mosh — osewa.dev
