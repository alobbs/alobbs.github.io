How the Claude Code team thinks about verification

The article explains that coding agents can verify work with evidence through verification loops using end-to-end, property, and differential tests, enabling more parallel agent work and higher quality; internal testing found a separate grader improved task success by up to 10 points. It recommends prioritizing end-to-end tests for real user flows, using property tests to catch hard-to-miss edge cases, and avoiding flaky or slow tests by running heavier checks before committing changes. Pulsar – cross-harness agent to agent communication and messaging

Pulsar is an MCP server that connects AI coding agents across harnesses—including Claude Code, Codex, OpenCode, pi, omp, Cursor, and Gemini CLI—on one local message bus. After npx pulsar setup, agents can discover, tag, and message each other individually, by selector, or in groups, with push delivery that can wake idle agents and support request/reply threads. It is safe by default and has no telemetry, with cross-machine messaging and remote control via Tailscale coming soon.
