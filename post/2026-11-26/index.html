Jiffies : The Heartbeat of the Linux Operating System (2024)

Jiffies are Linux kernel timer ticks since boot, incremented once per timer interrupt at frequency HZ and used for timekeeping and scheduling. The kernel exposes jiffies and jiffies_64 to handle overflow, with jiffies mapped to jiffies_64 on x86_64 and its lower 32 bits on x86_32. Kernel code reads jiffies and converts between jiffies and time units using HZ and helpers such as msecs_to_jiffies() and jiffies_to_msecs().
