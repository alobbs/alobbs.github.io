Baidu released ERNIE 5.5 Flash Base

Baidu released ERNIE-5.5-Flash-Base, a sparse Mixture-of-Experts language model with 280B total parameters and 14B activated per token, pretrained from scratch on 33.5T tokens with up to 128K training context and support for 1M-token fine-tuning and inference. The release provides base weights from the end of pretraining, before mid- or post-training, as a starting point for domain adaptation, instruction tuning, and reinforcement-learning research. It emphasizes efficiency through sparse MoE and hybrid sparse attention to balance capability, activated compute, and long-context costs.

The ULC Audio Codec is a Perfect Fit for the N64

The article explains that N64 audio was severely constrained by limited cartridge space and restricted access to the RSP, forcing most games to use short ADPCM samples instead of recorded music. It notes that Libdragon’s RSP-accelerated Opus decoder offers excellent quality and compression but is too slow for gameplay, while MP3 and QOA offer only marginal improvements. It argues that the obscure ULC codec is a perfect fit because it can deliver 44.1 kHz stereo at near-Opus bitrates while using only about 4% of the N64’s CPU time.

86open

The 86open project selected the Executable and Linkable Format (ELF) in 1999 as the standard binary file format for Unix and Unix-like systems on x86 processors. ELF is a flexible, extensible, cross-platform format used for executables, object code, shared libraries, device drivers, and core dumps, supporting different endiannesses and address sizes.

On vsyscalls and the vDSO (2011)

The vsyscall and vDSO mechanisms both accelerate certain Linux system calls by providing fast user-space access to functionality that does not require kernel mode. Vsyscall is the older mechanism, but its fixed memory location makes it useful to attackers, prompting patches to phase it out. Discussion of those patches highlights continuing disagreement in the community over how security issues should be handled.
