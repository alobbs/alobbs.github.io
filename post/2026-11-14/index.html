Red Hat Working To Improve Memory Tiering For QEMU VMs To Save RAM

Red Hat engineers are evaluating approaches to improve memory tiering for QEMU virtual machines so NVMe SSDs can replace DRAM in more scenarios and reduce RAM usage amid high memory prices. At KVM Forum 2026, Red Hat’s Peter Xu presented options including a new system call, full user-space tiering in QEMU, and using existing kernel APIs for migrating hotness. The existing-kernel-API approach is the current lead contender, requiring no kernel changes and only small QEMU changes, with possible improvement via a patch addressing MADV_PAGEOUT limitations.
