Vx – One Language, Every Chip

Vx is a systems programming language for heterogeneous computing that incorporates CPU, GPU, NPU, and accelerator memory into its type system, making errors like host dereferencing a device pointer compile-time failures. It treats data location as part of a value’s type, requires explicit transfers, and uses declared machine files to check memory capacity, topology, and other constraints against real hardware. The project provides machine files for NVIDIA, AMD, and Apple hardware, with support for macOS Apple Silicon and Linux x86_64.

  • Vx – One Language, Every Chip — vxlang.org

FTL: A new operating system for clouds

FTL is a new cloud operating system that runs each container as a userspace OS library implementing Linux abstractions like processes, VFS, and TCP/IP. FTL is compatible with Linux binaries and can also run specialized unikernel-like applications without POSIX abstractions.
